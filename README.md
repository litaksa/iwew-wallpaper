# Iwew Wallpaper

Interactive cozy room wallpaper with a walking cat, books, lights, and click-to-wake.

## Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) and login with GitHub.
2. Import this repository (`litaksa/iwew-wallpaper`).
3. Deploy — it will serve `index.html` as a static site.

Live preview will be at `https://iwew-wallpaper.vercel.app` (or your custom domain).

Made for fun. The cat walks around, sleeps, and can be woken up by clicking.
